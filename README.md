# Road to 21.1

A 21-week training plan for the London Landmarks Half Marathon on Sunday 4 April 2027. It mixes outdoor runs, Saturday parkrun and Peloton Bike sessions, with weekly nutrition habits and a London skyline that lights up as you tick off long runs.

**Open the plan:** https://mvprice3.github.io/half-marathon-training-plan/

Ticks are saved only in your own browser, so anyone using the link keeps their own progress.

## Editing

Change `training-plan.html`, then run `./build-pages.sh` to regenerate `index.html`, which is the page GitHub Pages serves.

This is general training guidance, not medical advice. This is a personal project and isn't affiliated with the race.
